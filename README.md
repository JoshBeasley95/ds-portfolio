# ds-portfolio

Joshua Beasley's data-science portfolio — both the **runnable projects** and the
**Astro website** that showcases them.

Each project is a bespoke, end-to-end demonstration (EDA → model → evaluation →
explainability) on **public/synthetic** data modeling the kind of problem a target
company faces — never a company's real data. Projects are generated by the
[Job Hunter](https://github.com/JoshBeasley95) project generator and published here.

## Layout
- `projects/<slug>/` — the runnable project: `analysis.py`, `charts/`, `RESULTS.md`,
  `README.md`, `INTERVIEW.md` (interview prep), and the source `writeup.mdx`.
- `src/content/projects/<slug>.mdx` — the site-rendered writeup (chart paths point to `/public`).
- `public/projects/<slug>/charts/` — chart images served by the site.
- `src/` — the Astro site (home, `/projects`, `/projects/<slug>`).

## Develop
```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
```

## Deploy (Vercel)
Vercel auto-detects Astro (build `astro build`, output `dist/`). Push to GitHub, import
the repo at vercel.com, deploy. Then set `PROJECT_GEN_SITE_BASE=<your-vercel-url>` in the
Job Hunter `.env` so future projects record a live `custom_project_url`.
